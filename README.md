# Vision-Question-Answering
This project includes model source code and model deployment.  
In this project, I only focus on Yes/No questions.  
There are 3 versions of this model:
- **TTCS 1**: **[Use Word-based Tokenization](https://colab.research.google.com/drive/1tNWl5GfcmTYoWUI8zT-CRdYZuX0SMmZi?usp=sharing#scrollTo=JD21cBWSfIjL&uniqifier=1)**.  
- **TTCS 2**: **[Use Subword-based Tokenization](https://colab.research.google.com/drive/1CBHMpznzA8bkpEjS8QFQiL302Ya-uEGj?usp=sharing&authuser=1#scrollTo=d4JZYhWIfy7t)**.  
- **TTCS_Final**: **[Apply Knowledge Distillation to try improving model ability](https://colab.research.google.com/drive/1W6Rvk2IW0dOubE5A88gI_xUr45AOqa5B#scrollTo=BgKANjkfj2fJ)**.
